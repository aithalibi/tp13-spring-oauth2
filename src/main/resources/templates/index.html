Authentification deleguee avec OAuth2 et OpenID Connect

Cette application ne gere aucun mot de passe. L'authentification est entierement deleguee a un fournisseur d'identite externe (Google, Keycloak ou un fournisseur conforme OIDC), qui delivre un access token et un id token.

Comment cela fonctionne

1. Redirection Vous accedez a /profile. Spring Security vous redirige vers l'ecran de connexion du fournisseur.
2. Authentification Vous saisissez vos identifiants chez le fournisseur — jamais dans cette application.
3. Code d'autorisation Le fournisseur renvoie un code sur /login/oauth2/code/{registrationId}.
4. Echange Spring echange ce code contre un access token et un id token (JWT signe).
5. Profil Les attributs du id token (nom, email, photo) sont affiches sur la page profil.
